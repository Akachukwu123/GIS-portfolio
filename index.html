DXF2GIS

It is a QGIS Plugin used for the conversion of CAD drawings to GIS layers. It supports POINT, LINE, LWPOLYLINE and SOLID entities, assigns the coordinate reference system selected by the user, preserves the original CAD layer and entity type as attributes, and exports the resulting layers to a GeoPackage.


Python PyQGIS
View plugin ↗

CoordNest

This is a web-based geospatial application that allows Nigerian surveyors to upload raw land coordinates and automatically generate compliant survey plans complete with bearings, distances as well as the location of the land, completely eliminating all manual forms of drafting and document preparation.


Javascript D3.js PhpMySQL
View project ↗

TrackDeck

A real-time delivery management software that allows users to manage and track deliveries for their businesses. It is a web-based platform that features interactive maps which allows the users to share real-time updates with their customers on the exact location of their delivery.


Mapbox WebSocket Node.jsMySQL
View project ↗

Nigeria Administrative Geographic Dataset

A structured geospatial dataset of Nigeria's 36 states, the FCT, 774 LGAs and 8,809 wards, containing geographic coordinates for individual wards. Available in JSON and GeoJSON formats, it provides organised administrative location data for GIS applications, mapping and location-based development.


JSON GeoJSON
View on Github ↗

Nigeria Health Facilities

An infographic dashboard presenting statistical insights into Nigeria's healthcare infrastructure, covering facility distribution, operational status, healthcare facility types and ownership categories. It summarises key healthcare indicators through visual charts to support a clearer understanding of the country's healthcare landscape.


ArcGIS QGIS
View Infographic ↗

OBIA Segmentation of RIver Niger

This project explores the application of Object-Based Image Analysis (OBIA) and satellite remote sensing techniques for identifying and extracting water bodies along the River Niger in Onitsha, Anambra State, Nigeria. The study was done to understand how object-based classification techniques can be applied to water-body extraction.


Python QGIS
